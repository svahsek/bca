## Detailed Syllabus: IGNOU BCA_NEWOL Semester 3

---

### MCS 208: Data Structures and Algorithms (Core, 4 Credits)

#### Unit 1: Introduction to Data Structures
- **Chapter 1:** Basic Concepts
    - Lesson 1: Definition and Classification
    - Lesson 2: Abstract Data Types (ADT)
- **Chapter 2:** Algorithm Analysis
    - Lesson 1: Time and Space Complexity
    - Lesson 2: Big O, Omega, Theta Notations

#### Unit 2: Linear Data Structures
- **Chapter 1:** Arrays
    - Lesson 1: Representation and Operations
    - Lesson 2: Applications
- **Chapter 2:** Linked Lists
    - Lesson 1: Singly Linked List
    - Lesson 2: Doubly and Circular Linked Lists
- **Chapter 3:** Stacks and Queues
    - Lesson 1: Stack Operations and Applications
    - Lesson 2: Queue Types and Applications

#### Unit 3: Non-Linear Data Structures
- **Chapter 1:** Trees
    - Lesson 1: Binary Trees and Traversals
    - Lesson 2: Binary Search Trees
    - Lesson 3: AVL and B-Trees
- **Chapter 2:** Graphs
    - Lesson 1: Representation and Traversal (BFS, DFS)
    - Lesson 2: Shortest Path Algorithms

#### Unit 4: Sorting and Searching
- **Chapter 1:** Sorting Algorithms
    - Lesson 1: Bubble, Selection, Insertion Sort
    - Lesson 2: Merge, Quick, Heap Sort
- **Chapter 2:** Searching Algorithms
    - Lesson 1: Linear and Binary Search

#### Unit 5: Hashing and File Structures
- **Chapter 1:** Hashing Techniques
    - Lesson 1: Hash Functions and Collision Resolution
- **Chapter 2:** File Structures
    - Lesson 1: Sequential, Indexed, and Direct Files
